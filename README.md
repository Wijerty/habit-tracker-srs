# Трекер привычек

Веб-приложение для планирования привычек, отметки выполнения и анализа прогресса.

## О проекте

«Трекер привычек» помогает одному пользователю формировать устойчивые привычки: задавать расписание, отмечать выполнение, получать напоминания и оценивать результаты за выбранный период.

Проект выполнен по варианту 2. Полное техническое задание опубликовано в Wiki.

## Возможности

- создание привычки с названием, описанием, периодичностью и временем напоминания;
- ежедневное расписание или выбор дней недели;
- отметка выполнения за текущий день и отмена отметки;
- календарь истории минимум за 30 дней;
- расчёт текущей серии выполнений;
- напоминания в 24-часовом формате;
- статистика за неделю и месяц;
- редактирование и архивирование привычек с сохранением истории.

## Требования

- браузер: Chrome, Edge, Firefox или Safari последних двух стабильных версий;
- экран: от 320 × 568 px;
- подключение к интернету для первой загрузки;
- данные хранятся в локальном хранилище браузера.

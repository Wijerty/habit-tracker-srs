# Трекер привычек

Учебный веб-проект по варианту 2. Прототип помогает создать привычки и отмечать их выполнение за текущий день. Данные хранятся локально в браузере.

## Что работает

- Создание привычки с названием, описанием, ежедневным расписанием или выбранными днями недели.
- Проверка обязательного названия, дней недели и времени напоминания.
- Просмотр списка активных привычек.
- Отметка выполнения за текущий день и отмена отметки.
- Сохранение привычек и отметок между посещениями в `localStorage`.

Время напоминания пока сохраняется только как настройка: уведомления ещё не реализованы. Календарь, серии выполнений, статистика, редактирование и архивирование также остаются в [беклоге](https://github.com/Wijerty/habit-tracker-srs/issues). Прототип не отправляет данные на сервер и не синхронизирует их между устройствами. Очистка данных сайта удалит сохранённые привычки.

## Запуск

Нужен Node.js 22 или новее; внешних npm-зависимостей нет.

```bash
npm install
npm start
```

Откройте `http://localhost:8080`. Остановить сервер можно сочетанием Ctrl+C. Для локальной работы нужен доступ к хранилищу браузера.

## Проверки и сборка

```bash
npm test
npm run build
```

Тесты проверяют валидацию, сохранение и восстановление данных, отметку и её отмену. Сборка копирует статические файлы в `dist/`. GitHub Actions запускает проверку файлов, синтаксиса JavaScript, тесты и сборку при изменениях в `main` и Pull Request.
